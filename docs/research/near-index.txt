- [Post experimental call function](https://docs.near.org/api-reference/post-experimental_call_function.md): Calls a view function on a contract and returns the result.
- [Post gas price](https://docs.near.org/api-reference/post-gas_price.md): Returns gas price for a specific block_height or block_hash. Using [null] will return the most recent block's gas price.

- [Post block effects](https://docs.near.org/api-reference/post-block_effects.md): Returns changes in block for given block height or hash over all transactions for all the types. Includes changes like account_touched, access_key_touched, data_touched, contract_code_touched.

This endpoint is solely used for bridge currently and is not intended for other external use cases.
